What is Link State Routing?

Link State Routing is a routing protocol where each router has complete knowledge of the network topology. This comprehensive understanding enables optimal path selection and efficient packet forwarding.

Key Characteristics:

  • Complete Topology Knowledge: Each router knows the entire network topology
  • Dijkstra's Algorithm: Uses shortest path algorithm for optimal routing
  • Neighbor Information Sharing: Routers share information only about their direct neighbors
  • Information Flooding: Link state advertisements are flooded throughout the network
  • Fast Convergence: Quick adaptation to topology changes

Main Protocols:

  • OSPF (Open Shortest Path First)
  • IS-IS (Intermediate System to Intermediate System)

How Link State Routing Works

Link state routing operates through a systematic 7-step process:

1

Neighbor Discovery

Each router discovers its directly connected neighbors and the cost/distance to reach them.

2

Link State Advertisement (LSA)

Each router creates a Link State Packet containing information about its neighbors and link costs.

3

Flooding

Each router floods its LSA to all other routers in the network. Every router receives a copy of every other router's LSA.

4

Topology Database Construction

Each router builds a complete topology database (map) of the network using all received LSAs.

5

Shortest Path Calculation

Each router runs Dijkstra's algorithm on the topology database to calculate shortest paths to all destinations.

6

Routing Table Creation

Based on shortest path calculations, each router creates its forwarding/routing table.

7

Packet Forwarding

When a packet arrives, the router consults its routing table and forwards the packet to the appropriate next-hop router.

Dijkstra's Algorithm

Dijkstra's algorithm is the core component of link state routing that finds the shortest path from a source node to all other nodes in a weighted graph.

Algorithm Steps:

  1. Initialize: Set distance to source as 0, all others as infinity
  2. Create unvisited set containing all nodes
  3. Main Loop: While unvisited set is not empty:
    • Select node with minimum distance from unvisited set
    • Mark it as visited
    • For each unvisited neighbor, calculate tentative distance
    • If tentative distance is less than current distance, update it
  4. Complete: All shortest paths are now computed

Time Complexity: O(n²) where n is the number of nodes

Space Complexity: O(n) for storing distances and visited nodes

How This Animation Works

This interactive simulator demonstrates link state routing through visual animations and user controls:

Using the Simulator:

Creating the Network:

  • Click 'Add Sender Node', 'Add Router', or 'Add Receiver Node' to add nodes
  • Drag nodes around the canvas to rearrange the network topology
  • Click 'Connect Nodes' button to enter connection mode
  • Set the desired link cost in the input field (1-20)
  • Click two nodes to create a weighted link between them

Packet Transmission:

  • Select a sender from the dropdown menu
  • Select a receiver from the dropdown menu
  • Click 'Send Packet' to start the animation
  • Red packet represents the request traveling from sender to receiver
  • Blue packet represents the response traveling back from receiver to sender
  • Yellow/lime highlighting shows the active path being used

Algorithm Operation:

  • The simulator automatically calculates the shortest path using Dijkstra's algorithm
  • Path calculation considers all link costs to find the optimal route
  • If no path exists between sender and receiver, an error message is displayed
  • Animation speed can be adjusted using the slider control

Additional Features:

  • Enable 'Show Routing Tables' to see forwarding information at each router
  • Click 'Remove Selected Node' to delete a selected node and its connections
  • Use 'Reset Network' to return to the default sample topology
  • The simulator starts with a pre-configured sample network for immediate experimentation
